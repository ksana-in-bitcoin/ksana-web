# Security policy

Do not describe a vulnerability in an issue, a discussion or a pull request. Report it privately through GitHub's
private vulnerability reporting (this repository's Security tab, "Report a vulnerability"), as the Ksana repository's
[security policy](https://github.com/ksana-in-bitcoin/ksana/blob/main/SECURITY.md) says; it also says what to include,
what counts and which audits were done.
